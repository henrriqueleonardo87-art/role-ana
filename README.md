# Ana Gabriela & Leonardo // O Convite ✨

Aplicação web exclusiva desenvolvida com maturidade, carinho e bom gosto para Ana Gabriela.

### 🚀 Sobre o Projeto
- **História:** Cinco anos depois de se conhecerem no ponto de ônibus em 2021, o convite oficial para o primeiro encontro de verdade.
- **Conceito:** Uma proposta sofisticada e acolhedora — gastronomia de alto nível, transporte com cuidado e atenção, boa conversa e leveza.
- **Tecnologias:** HTML5 semântico, CSS3 moderno, Vanilla JavaScript & Web Audio API sintetizada.
- **Deploy:** Otimizado para hospedagem estática na Vercel.
